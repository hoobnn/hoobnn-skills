# 零成本诊断手册：先问「信息在不在」，再决定往哪使劲

诊断成本远低于一轮训练。实战里最贵的教训是在烧掉四轮训练之后才做诊断——
**应该第一轮失败后就做**。以下每条都是纯 CPU、只读已有 val 概率 / 标注 / 源码即可完成。

## A. 动手前

### A1. 审计管线里已有的再平衡机制
`WeightedRandomSampler` / 逆频率类别权重 / 决策权重重搜 / 损失加权——
**已存在的再平衡机制会吸收任何同轴的新干预**（加样本、LA-Loss、Balanced Softmax、
Copy-Paste 都在同一根「先验轴」上）。想在稀有类拿增益，必须找不被吸收的干预点：
改变的应该是**每个样本携带的信息**，而不是样本的数量或权重。
检查方法：读源码 + 读实际 run 的 `args.yaml`（不只看默认值）。
反例同样有价值：另一题逐条核实后发现 0 个活跃再平衡机制，跨题规律不成立。

### A2. 对称互换 vs 边缘偏移
所有沿先验轴的全局重标定（类别权重、阈值、决策权重）只能修正**边缘分布偏移**，
碰不到**对称互换错误**。用混淆矩阵分解：实战净边缘不平衡 17 个、对称互换 28 个（62%），
⇒ 重标定天花板已知且很低，不做；应改**信息来源**。

### A3. 数据的原子结构
「更细的划分」在数据里可能没有对应物：隐藏集时长只有 {full, 1s, 0.5s} 三个原子值，
加 1.5~3s 边界是空操作。建议方向前先看数据的离散结构。

### A4. 预处理删掉了哪些量
做解耦 / 裁剪 / 归一化类改造前，显式检查 `resize` 抹掉绝对尺度、per-image 标准化抹掉亮度、
裁剪抹掉位置关系。实战：4 个参数的「绝对尺寸」LogReg 打到 .78，千万参数 CNN 只有 .81——
最强线索被 resize 到 224 蒸发了。

### A5. 信息有没有路径到达做决策的那一层
一类干预反复失败时，读源码确认决策分支能看到什么（逐 FPN 层全卷积分类分支只知道
「在哪一层激活」，层内没有绝对尺寸量）。路径不存在时，喂再多、加再大权重都没用。

### A6. 后备方案也先定价
方案 A 失败才启动方案 B 是常规做法；更好的是 A 没跑之前先零成本测 B 的天花板。
技巧：「错误集占比 vs 全体占比」这个对比不依赖代理量的绝对精度（分子分母同样被低估）。
实战：B 想攻的主错误方向恰恰最不像它假设的成因，降级为「需新证据才启动」。

### A7. 架构改动先在 CPU 跑 3 步再上 GPU 窗口
四项必验：**初始等价**（零初始化时与原模型逐位相同）、**新增信息非常量**
（若是常量则机理从根上不成立）、**超参 diff 为空**、**3 步冒烟 exit 0**。
实战拦下「深度卷积不能加输入通道」（能跑通但结果已废）和 EMA 键不匹配崩溃。

### A8. 「已证伪」结论隐含的前提
写下「某轴已被占据 / 已证伪」时，同时写下它依赖的前提；定期回头检验。
检验结果可能推翻原结论，也可能加固它（实战：撤掉采样器后稀有类更差，原结论升级为定论）。
Decoupling / cRT / LWS 类方法的适用前提是「尾类绝对数 × epoch 数足以形成表征」，
判断依据不是不平衡比例。

## B. 失败后

### B1. 同一失败签名重复出现 = 问题定义错了
四个机理不同的干预在同一类上全部呈现「TP +4~5 / FP +21~39」——
瓶颈不在任何一个干预的实现方式上，而在输入信息本身。停下来诊断，不要换第五个方向。

### B2. 区分「看到了没敢判」与「根本没看见」
把每个稀有类的 FN 按「模型给该类的概率」与「正确负类的同一概率」对比：

| 性质 | 判别 | 处置 |
|---|---|---|
| 看到了但没敢判 | p 显著高于负类基线但未越阈值 | 决策 / 校准问题，**可攻** |
| 根本没看见 | p ≈ 负类基线 | 信息不在输入里，**放弃**，额度投别处 |

再逐张目视确认（p 最低的 12 个 FN 里肉眼也找不到裂纹）。
**oracle 增益大 ≠ 值得攻**：用「可达的 oracle」而非名义 oracle 排优先级。
转攻另一类之前做目视前置验证：新视野下人眼是否可判，机理前提成立才投训练。

### B3. 分维度分解：先搞清失分在哪个维度
用「类别合并后重新评测」把总指标拆成检出 / 分割维与分类维。实战：类别无关 AP50 ≈ .94
（已饱和），缺口全在分类维；oracle 只改 54 个实例的类别 → +.074，是差距的 2.5 倍。
之后所有候选按维度看增益落点：**增益落在饱和维 = 无效增益**，且往往伴随瓶颈维恶化
（「总分涨、瓶颈维恶化」在同一题复现三次，其中一次线上 −0.029）。

### B4. 无标签代理指标：同域留出集测不出域外过拟合
留出集与训练集同域时，「训练更久 → 分布内更锐利 → 未见域上更保守」结构上测不出。
在真实测试集上跑无标签代理：预测数量、空图数、长度 / 面积比、前景像素占比、均值概率。
建立代理指标与已知线上结果的对应关系（空图 ↑ + 线数 ↓ + 长度比 < 1 = 某次 −0.00164 的签名），
之后直接用来预警；代理与离线增益矛盾时以代理为准，修正版必须让代理回到锚点水平才允许投。

### B5. 训练不稳定伪装成增益
OneCycle 峰值 lr 区可复现的 val 塌陷 + 稀疏 eval ⇒ best-epoch 带「采样点是否避开坑」的运气；
长训练天然更多采样点，「长训练更好」可能纯粹是采样运气。
规程：同时看终局指标与曲线形态；长训练优势只在 best-epoch 而终局持平，先怀疑采样偏差；
对照臂同机同设备同调度。

### B6. 方向正确 ≠ 口径正确（同一诱惑单日三次）
重搜决策权重口径下的数字方向与假设一致（假设说「更宽视野帮 small」，重搜口径就显示 small 大涨），
因而比随机噪声更有说服力——这正是它危险的地方。识别：把重搜权重与冻结权重并排看，
差一个数量级就说明增益依赖校准自由度。任何跨口径数字先换算到冻结口径，换算不了就不进判定。

### B7. 相反方向的类别需求无法用单一参数满足
目标类改善与非目标类恶化数量级相当且方向稳定 ⇒ 先怀疑「需求方向相反」（small 要宽视野，
cracked 要近视野），而不是继续扫参。出路是多视图或接受放弃一类。

### B8. 合成 / 增强数据：用「模型能否区分合成与真实」当判据
单一低阶统计量（色调差）对齐到 +0.00 不等于消除域偏移；终局模型在从未参与训练的合成
holdout 上置信度 0.96 vs 真实 0.71，「是否为合成」被学成捷径特征。
正确判据：留出合成 holdout，比置信度与逐类 F1。
召回提升 ≠ 方案有效：TP +5 但 FP +35，结论分两层——「机理部分成立」与「该实现形式不可用」，
保留机理换实现（离线合成池 → 在线增强，真实与增强样本共享同一 instance）。

### B9. 生成式候选必过内容正确性门
MOS 只测听感不测内容，生成式修复器可以用幻觉换高 MOS（NISQA +0.73 但 CER 19.7%→75.4%，
把中文说成英文）。先跑内容门（ASR / 一致性）再跑质量门，内容保不住则早止损。

### B10. 解耦不必然更强
把分类从检测器解耦成独立分类头，拿着更容易的考卷（GT 裁剪）仍输共享特征 2.9pt。
「空间存在 ≠ 空间可达」：被证伪的是具体实现，不是「分类是瓶颈」这个诊断。
「oracle 上限存在」是信息存在的证据，不是「随手融合就能拿到」的承诺。

### B11. 发现新失败模式后，回头复核旧判断
定位到「看起来像缺权重、实为代理配置」的新失败模式后，回头重验此前用同类表象做的判断
（复核成本几分钟，误判一条「外部约束关闭」会永久埋掉一条可行的轴）。
