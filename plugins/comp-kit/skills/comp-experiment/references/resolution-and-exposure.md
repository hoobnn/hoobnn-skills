# 单步分辨率与暴露度

线上榜单的测量精度有限。判断一次线上反馈是信号还是噪声之前，先算两个数。

## 单步分辨率：翻动 1 个预测单元，线上指标变多少

| 指标类型 | 标定方法 | 实战读数 |
|---|---|---|
| Accuracy / Macro-F1 | 1/N；Macro-F1 按类反解，稀有类最贵 | 141 段 → 0.00709 |
| F1（线 / 实例级匹配） | 用 TP/FP/FN 反解一条线的 ΔF1，端点敏感 ±7% | 3000 线 → 2.0×10⁻⁴ / 线 |
| 多类稀有类 | 每类单独算「单例敏感度」 | n=95 的类翻 1 例抖 0.8~1.3% |
| mAP（COCO 式） | dev 上「只改 k 个实例的类别 / 掩膜」的 oracle 反解 | 15.7 当量 ≈ +0.074 |

判据分级：`< 1 步不可分辨 / 1~3 步弱信号 / > 3 步真实差异`。写进仓库入口文件的「基线参考指标」节，
所有线上判读对照它。`assets/step_resolution.py` 的 analytic 模式按公式反解，empirical 模式对任意指标
随机翻一个单元重算（mAP、线级 F1 用这个）。

实战因此撤回的「线上证伪」：flip-TTA（3/141 暴露度）、双 seed（4/141）、两个集成权重的「w1 胜出」
（差 0.00008 = 0.39 条线）。仍然成立的证伪：−0.029（两个独立数据点互证）、−0.00645（≈ 3.4~13 个
稀有类实例净翻转）、−0.00164（≈ 8 条线，超 5 线门槛）。

## 暴露度：候选相对线上锚点改动了多少个预测单元

相对**线上锚点包**算，不是相对离线基线。它是必要条件（决定能否被测出），不是充分条件（不决定正负）：
实战 4 次「暴露度够 + 离线更好 → 线上仍为负」。

| 离线增益 | 暴露度 | 处置 |
|---|---|---|
| 显著为正（CI 不跨零） | ≥ 门槛 | 可投（唯一该投的情形，仍可能翻车） |
| 显著为正 | < 门槛 | 不投，测不出白扔额度；候选保留作后续基座 |
| 持平 / 为负 | 任意 | 不投 |

门槛定法：门槛 × 单步分辨率 ≥ 3 步（141 段取 ≥ 20，900 图取 ≥ 15 线）。

离线增益的大小决定改动有没有价值；离线增益的类别分布 × 测试集的类别构成决定这次提交能不能测出来。
实战：池化 OOF +0.068（13.6 倍门槛、逐折非负），但涨幅最大的类在 A 榜基线里只被预测 2 次，
只换来 17/141 翻转 → 弃投但不否定改动，作后续候选的基座。

## 流向分解：最有价值的一招

不停在「改了多少个」，拆「往哪个方向改」并用单步分辨率给每种流向定价。实战：候选相对锚点只改
59/8401 个实例，拆流向后定位 cracked→normal 的 11 例，仅此一项就值 −0.019，足以解释全部 −0.00645
跌幅；反向的 31 例即使全对上限也只 +0.019。结论是改设计（只在已判劣果的实例内部重分配），不是调参。

`assets/exposure.py` 直接输出：改动单元数、各流向的对 / 错 / 净等效实例数、按单步定价的 Δ；净等效实例数
≤ 4 自动标「噪声带内」。纯离线、不消耗额度。

## 两条配套判读

- 弱正信号 + CI 跨零 = 高危，不是「差一点就过」。实战两次线上反转的信号量级（+0.0077 / +0.0093）
  与后来一次「差一点就过」的 +0.0070 完全相同。
- 目标类的两种失败性质分开：「未变差只是未变好」（TP 没掉、FN 没涨，干预中性）与「明显变差被非目标类
  掩盖」（干预有害）。总分上看不出区别，归因工具要直接判定输出。
