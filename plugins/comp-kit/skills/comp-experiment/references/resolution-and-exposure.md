# 单步分辨率与暴露度：离线差异能不能被线上测出来

线上榜单的测量精度是有限的。判断一次线上反馈「是信号还是噪声」之前，先算两个数。

## 1. 单步分辨率（per-step resolution）

**定义**：翻动 1 个预测单元（一条样本 / 一条线 / 一个实例），线上指标变多少。

| 指标类型 | 标定方法 | 实战读数 |
|---|---|---|
| Accuracy / Macro-F1（N 个样本） | 1/N；Macro-F1 按类反解，稀有类最贵 | 141 段 → **0.00709** |
| F1（线 / 实例级匹配） | 用 TP/FP/FN 反解一条线的 ΔF1，端点敏感 ±7% | 3000 线 → **2.0×10⁻⁴ / 线** |
| 多类稀有类 | 每类单独算「单例敏感度」 | n=95 的类翻 1 例抖 0.8~1.3% |
| mAP（COCO 式） | 用 dev 上「只改 k 个实例的类别 / 掩膜」的 oracle 反解 | 15.7 当量 ≈ +0.074 |

**判据分级**（可移植）：`< 1 步：不可分辨 / 1~3 步：弱信号 / > 3 步：真实差异`。
把它写进仓库入口文件（CLAUDE.md「基线参考指标」节），所有线上判读都对照它。

**已因此撤回的错误结论**（实战）：

- flip-TTA「线上证伪」→ 实为 3/141 暴露度下的噪声，不可分
- 双 seed「线上证伪」→ 4/141，不可分
- 两个集成权重「w1 胜出」→ 差 0.00008 = 0.39 条线，统计不可分

**仍然成立的证伪**（幅度远超噪声）：−0.029（两个独立数据点互证）、
−0.00645 ≈ 3.4~13 个稀有类实例净翻转、−0.00164 ≈ 8 条线 > 5 线门槛。

## 2. 暴露度（exposure）

**定义**：候选相对**线上锚点包**改动了多少个预测单元（不是相对离线基线）。

**暴露度是必要条件（决定能否被测出），不是充分条件（不决定正负符号）。**
实战 4 次「暴露度够 + 离线更好 → 线上仍为负」。

**判定表**（写进门禁脚本 docstring）：

| 离线增益 | 暴露度 | 处置 |
|---|---|---|
| 显著为正（CI 不跨零） | ≥ 门槛 | **可投**（唯一该投的情形；仍可能翻车，接受） |
| 显著为正 | < 门槛 | 不投，测不出，白扔额度；候选保留作后续基座 |
| 持平 / 为负 | 任意 | 不投 |

暴露度门槛的定法：门槛 × 单步分辨率 ≥ 3 步（如 141 段取 ≥ 20，900 图取 ≥ 15 线）。

## 3. 「离线增益大」与「线上可测」是两个独立维度

离线增益的**大小**决定改动有没有价值；离线增益的**类别分布 × 测试集的类别构成**
决定这次提交能不能测出来。实战：池化 OOF +0.068（13.6 倍门槛、逐折非负），
但涨幅最大的类在 A 榜基线里只被预测 2 次 → 只换来 17/141 翻转 → 主动弃投，
**但不否定改动本身**，作为后续候选的基座继续推进。

## 4. 暴露度流向分解（最有价值的一招）

不停在「改了多少个」，拆「往哪个方向改」并用单步分辨率给每种流向定价：

实战：候选相对锚点只改 59/8401 个实例，拆流向后定位 **cracked→normal 的 11 例**，
按单步表仅此一项就值 −0.019，足以解释全部 −0.00645 跌幅；反向的 31 例即使全对
上限仅 +0.019，实际远未兑现。→ 结论是**改设计**（只在已判劣果的实例内部重分配，
不改是否劣果的判定），不是调参。

纯离线、不消耗额度，能把「该不该保留某成员」从猜测变成有据判断。
工具应直接输出：支撑样本量 n、TP/FP 绝对变化、等效翻转实例数、单例敏感度，
等效实例数 ≤ 4 的自动标「噪声带内」。

## 5. 两条配套纪律

- **弱正信号 + CI 跨零 = 高危，不是「差一点就过」**。实战两次线上反转的信号量级
  （+0.0077 / +0.0093）与后来一次「差一点就过」的 +0.0070 完全相同。
- **目标类的两种失败性质要分开**：「未变差只是未变好」（TP 没掉、FN 没涨，干预中性）
  与「明显变差被非目标类掩盖」（TP 掉了或 FN 涨了，干预有害）。总分上看不出区别，
  归因工具要直接判定输出。
