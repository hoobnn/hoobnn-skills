# experiment-log.md 单条记录模板

新记录加在文件顶部（倒序）。同日多次实验合并在一个日期标题下也可以，但每次提交单独成段。

```markdown
## <YYYY-MM-DD> <方法一句话>（<结果标签：新高 XXXX / 微增 / 证伪 / 管道验证>）

- 方法：<做了什么，单变量改动是什么，其余什么被冻结>。实现：`src/<脚本>.py`。
- 配置：<训练窗口 / 折数 / epochs / seed / 关键超参>，与 <对照实验> 仅差 <该变量>。
- 离线：<OOF 指标，含捕获率与排序指标；分季/分折稳定性一句话>。
- 产物：`submissions/<方案名>/output.csv`，<行数> 行、合法性校验通过，MD5 `<md5>`。
- 提交：账号 `<脱敏账号>`，`submitId=<id>`，`<状态>`，得分 `<线上得分>`，
  较 <对照> <±Δ>，提交后该账号剩余 <N> 次。
- 结论：<这次实验回答了什么问题；下一步做什么 / 放弃什么>。
```

要点：

- **结果标签放标题里**，翻日志时一眼定位新高与死路。
- 线上得分记**完整精度**（官网给几位记几位）——探针拟合与精确复现校验都依赖完整数值。
- 未上线的纯离线实验省略"提交"行，其余字段不省。
- 证伪实验的"结论"行写清死因，复盘时直接汇入证伪清单。
- 多账号时每条提交都记账号（脱敏，如 `***5152`）与剩余次数，这是 comp-submit
  预算管理的数据源。

## 真实样例（脱敏节选）

```markdown
## 2026-07-21 窗口秩集成与单日共识探针（新高 6868.47）

- 方法：复用三套已有 Q4 预测，将每天 89 个窗口总价做日内 z 标准化后融合窗口秩，
  由精确 DP 选窗；实现为 `src/blend_window_submissions.py`。
- `***5152` 第二发：保持 58 天不变，只将三套模型放电峰一致偏晚的 `2026-02-03`
  从 `(50,66)` 修为 `(50,70)`；`submitId=2079497721240735744`，`SUCCESS`，
  新高 `6868.46654529101`，提升 `20.697185214084`。已提升为 `submissions/output.csv`，
  MD5 `4b48fa4ef7d52c2a5b6fecbb1b3d2406`。
- 结论：新模型适合作单日共识探针，不适合全局取代线上已校准基底。
  两账号当日次数用完：`***1023=0`、`***5152=0`。
```
