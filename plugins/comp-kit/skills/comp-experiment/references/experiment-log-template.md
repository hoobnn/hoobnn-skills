# experiment-log.md 单条记录模板

新记录加在文件顶部（倒序）。同日多次实验可合并在一个日期标题下，但每次提交单独成段。

```markdown
## <YYYY-MM-DD> <方法一句话>（<结果标签：新高 X / 微增 / 证伪 / 管道验证 / 外部约束关闭 / 弃投>）

- 预登记：主门 <阈值/口径>、否决门 <...>、暴露度门 <≥N>；处置表见 <日期> 条目（或 /comp-gate 输出）。
- 方法：<唯一变量是什么，其余什么被冻结>。实现：`src/<脚本>.py`。
- 配置：<训练窗口 / 折数 / epochs / seed / 设备 / 关键超参>，与 <对照臂> 仅差 <该变量>。
- 证据分级：<smoke / 独立 dev / A 榜 / B 榜>。
- 离线：<同口径指标 ± 配对 CI（按来源组）；分折 / 分组 / 分类稳定性一句话；瓶颈维度读数>。
- 暴露度：<相对线上锚点改动 N/M 个单元；流向分解一句话>。
- 产物：`submissions/<方案名>/<文件>`，<行数/条数>，校验全过，
  SHA-256 `<sha>`，<字节数> B，MD5 `<md5>`。
- 提交：账号 `<脱敏>`，<时间>，额度 <前>→<后>，回读指纹一致，
  得分 `<线上得分完整精度>`，较 <锚点> <±Δ>（= <k> 个单步分辨率）。
- 结论：<回答了什么问题；下一步做什么 / 放弃什么；这条结论依赖的前提>。
```

要点：

- **结果标签放标题里**。「外部约束关闭」（OOM / 权重拉不到 / 平台失败）与「证伪」严格分开。
- 线上得分记**完整精度**，Δ 换算成单步分辨率的倍数——小于 1 步的差异写「不可分辨」，不写证伪。
- 未上线的纯离线实验省略「提交」行，其余字段不省；弃投要写弃投原因（暴露度不足 / 未过门）。
- 证伪实验的「结论」写清死因与前提，复盘时直接汇入证伪清单。
- 多账号 / 多赛题时每条提交都记账号与额度前后值，这是 comp-submit 预算与回执的数据源。

## 真实样例（脱敏节选）

```markdown
## 2026-09-10 SAM2-tiny box-prompt 掩膜精修（证伪）

- 预登记：主门 dev ≥ 锚点 +0.0010；AP90/AP95 同升；否决门 AP50 不降。
- 方法：唯一变量 = 掩膜来源（每条记录用其 bbox 作 box prompt 生成新多边形），
  检测 / score / top-150 / 合并全部冻结。实现 `src/verify_sam_refine.py`。
- 证据分级：独立 dev（fold0 102 图，官方口径）。
- 离线：control d=0.6 = 0.9355911（与锚点逐位一致，对照干净）；14 个变体无一为正，
  最优 −0.0067；AP90 −0.0316 / AP95 −0.0219，恰在本想攻的高 IoU 档全面更差。
- 结论：门禁 FAIL，不投；机理级证伪——通用分割器的图像证据边界与本题标注风格
  （略收紧的手绘多边形）不吻合。边界维度的 +0.040 奖金池不在后处理层，只剩训练期边界质量一条路。
  前提：仅对 box-prompt 精修成立，不覆盖训练期边界监督。
```
