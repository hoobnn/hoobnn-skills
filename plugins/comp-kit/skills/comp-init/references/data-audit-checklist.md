# 数据审计清单

每条都是实战中「拿到数据跑过才知道、且推翻了纸面推断」的事实。审计结论写进
experiment-log「数据审计实测」节，标明哪些先验被证伪。

## 1. 文件与编码
- [ ] 下载链接是否真的指向所写的东西（实战：「提交样例」链接指向训练集）。
- [ ] zip 内非 ASCII 文件名的编码（GBK 需按 cp437→gbk 还原，`unzip` 会乱码）。
- [ ] 每个数据集的行数 / 样本数、尺寸 / 时长分布、列清单；训练与测试的列差异。
- [ ] 缺失值分布；**异常但合法的数据**（负价、离群）先确认官方口径再决定是否处理。

## 2. 分组结构（决定验证协议）
- [ ] 文件名后缀 / 前缀（`_aug1` 增强副本、case_id 段）→ 真实独立样本数。
- [ ] EXIF / `creation_time` / 缩略图近重复并查集 → 来源视频 / 拍摄批次数。
- [ ] 每个来源组的类别构成：组全部单一类别时 GroupKFold 与 StratifiedKFold 冲突，先裁决。
- [ ] 稀有类的绝对数与组数（class 2 仅 1 组 ⇒ 离线不可估，写进入口文件）。
- [ ] 用代理探针量化随机划分的高估幅度（comp-experiment「验证协议先于建模」）。

## 3. 训练 / 测试信息不对称
- [ ] 测试期拿不到的列（历史真实标签的 lag / rolling、未来信息）逐一列出。
- [ ] 公开训练集与隐藏测试集是否**同一生成批次**（合成数据：id 重叠、模板重复）——
      同批次上的穷举规则默认不可外推。
- [ ] 测试集私有的评测元数据（忽略区、trial 结构）：本地只能近似，写明近似方式。
- [ ] 测试集与训练集是否来自不同原始视频 / 场景（域偏移）→ 需要域外代理集。

## 4. 标注口径
- [ ] 训练标注 id 与提交 id 的映射（1/2 → 0/1）。
- [ ] 标注只描绘可见区域还是 amodal；多边形 / RLE；越界 / 退化记录官方如何处理。
- [ ] 相对判断类标签（「small 相对同穗邻居」）的参照系是局部还是全局——
      用全局统计判别的假设先实测（实战：相对面积区间完全重叠，证伪）。
- [ ] 标签可判性：随机抽稀有类样本目视，crop 视野内人眼能否判断；
      不能则「信息不在输入里」，模型也救不回来。

## 5. 数据的原子结构
- [ ] 离散取值集合（时长只有 {full, 1s, 0.5s}；answer 只有 14 个标签）——
      「更细的划分」在数据里可能没有对应物。
- [ ] 每题材料 / 每样本上下文长度：小到能全塞 prompt 时不需要检索召回。

## 6. 下界与兜底
- [ ] 一族常数策略各自得分（全 A / 全 B / insufficient / 官方 demo），取最高者为兜底。
- [ ] 官方 baseline 能否跑通、硬编码路径、缺失函数。
