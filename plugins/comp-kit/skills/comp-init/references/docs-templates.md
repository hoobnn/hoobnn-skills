# docs/ 知识库文件模板

每个文件的骨架。生成时替换尖括号占位符；没有内容的小节保留标题并标注"待补充"，
让缺口显式可见。

```markdown
> 依据：<规则原文冻结条款，存档路径>。冻结死线 <日期时间>（B 榜发布前）；
> 自设方案锁定截止 <日期>；演练打包 <日期>。

## 冻结包构成
| 成员 | 路径 | SHA-256 | 字节数 |
|------|------|---------|--------|

## 单入口脚本 / 依赖 / README 披露
- [ ] 入口：`src/<entry>.py --device {cpu,mps,cuda}`，固定冻结参数
- [ ] `requirements.txt`（uv export，pin 版本）；复现环境 Python <版本待确认>
- [ ] `grep pretrained=True` 为空；`HF_HUB_OFFLINE=1` 跑通
- [ ] README：复现命令、预期指纹、时长、许可与外部数据披露

## 逐字节回归
- [ ] 解压到临时目录跑 A 榜图，与线上最佳包逐位一致（跨设备则逐记录 IoU > 0.999）

## 登记

- [ ] `chmod 444` + `solution.frozen.zip` 另存
```
