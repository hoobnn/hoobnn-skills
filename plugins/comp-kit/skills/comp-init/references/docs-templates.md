# docs/ 知识库文件模板

每个文件的骨架。生成时替换尖括号占位符；没有内容的小节保留标题并标注"待补充"，
让缺口显式可见。

## docs/requirements.md — 权威整理

```markdown
# 赛题要求权威整理

> 整理自官网原文（存档见 metadata/ 与 docs/source-material.md）。有争议以本文为准；
> 官网更新时同步本文并标注日期。

## 任务定义
<输入什么、输出什么、预测/决策目标>

## 评分
- 公式原文：`<...>`
- 最终排名只看：<X>
- 下界 / 上界：<全零得分> / <oracle 得分>

## 数据
<每个文件：路径、行数、列、粒度、缺失>

## 硬约束
<输出合法性规则、外部数据、代码审核、预训练模型规则>

## 提交
- 文件名 / 列名与顺序 / 行数 / 编码 / 时间格式
- 每日提交次数：<N>
```

## docs/experiment-log.md

首条记录格式见 comp-experiment skill 的
`references/experiment-log-template.md`。初始化时只写标题与说明：

```markdown
# 实验记录与提交分数

更新时间：<日期>

> 记录纪律见 comp-experiment skill：每次实验记方法、单变量改动、配置、离线指标、
> 产物 MD5、submitId、线上得分、剩余提交次数、结论。失败实验同样记录。
```
