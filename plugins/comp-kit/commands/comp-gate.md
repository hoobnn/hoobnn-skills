# Claude Command: comp-gate

调用 comp-kit 插件的 `comp-experiment` skill（`references/gate-design.md`），在当前仓库
`docs/experiment-log.md` 顶部写一条「预登记」条目，供之后 `/comp-log` 回填结果。

执行要求：

1. 先读取 `gate-design.md` 与仓库入口文件（CLAUDE.md）里的单步分辨率、线上锚点、已关闭方向。
2. 从 `$ARGUMENTS` 与上下文确定：对照臂（唯一线上验证过的锚点）、唯一变量、口径
   （权重 / 设备 / dev 集 / 后处理）。缺任一项向用户逐项询问，不替用户拍。
3. 阈值用单步分辨率换算（主门 ≥ 3 步；否决门允许恶化 ≤ 1 个等效实例；暴露度门 ≥ 门槛），
   写明数值来源；已知「A 类有效 B 类有害」的方向必须有否决门。
4. 处置表穷举结果区间（过 / 主门过否决门不过 / 主门不过目标类正向 / 都不过 / 未跑满），
   每段写处置**和不做什么**（不变体化、不改门再试、不降 batch）。
5. 检查判据的可自执行性：每段指向的动作现在是否做得了，引用的脚本 / 包是否存在。
6. 若仓库有 `src/gate_candidate.py`，核对脚本常数与本次预登记一致；不一致先改脚本并在条目里注明。
7. 写完提示用户：出分或跑完后用 `/comp-log` 回填，判据不再改动。
